# VELA AI Agents (safe scaffold)

Five disabled planning agents: creative, video, brand, quality, publishing.

**Safety:** No Shopify connection, no publishing, no API credentials, no external calls, no billing. This repository was reported PUBLIC at setup time; make it private in GitHub settings before storing any business data.

Open-Higgsfield-AI is an **optional, disabled** integration reference, not installed or executed. Its generation provider may charge for API usage. No upstream code is copied.

Run offline validation with `node --test` (Node.js 18+). The demo only produces local, hypothetical draft metadata.

Activation requires a separate review of provider terms, permissions, costs, and secret handling. Do not put secrets in VITE_* variables or client-side code.
